# Level 16 — DSA: Arrays

Beginner Java practice for array traversal, searching, counting, and the two-pointer technique.

## Programs

| No. | Program | File |
|---:|---|---|
| 1 | Sum of Array Elements | `ArraySum.java` |
| 2 | Find Maximum Element | `ArrayMaximum.java` |
| 3 | Find Minimum Element | `ArrayMinimum.java` |
| 4 | Count Even and Odd Numbers | `EvenOddCount.java` |
| 5 | Linear Search | `LinearSearch.java` |
| 6 | Count Occurrences | `CountOccurrences.java` |
| 7 | Reverse Array using Two Pointers | `ReverseArray.java` |
| 8 | Reverse Array Practice (second example) | `ReverseArrayPractice.java` |
| 9 | Find Second Largest Distinct Element | `SecondLargest.java` |

## Concepts Practiced

- Array traversal using enhanced `for`
- Finding maximum and minimum values
- Counting elements using conditions
- Linear search, `break`, and boolean flags
- Reversing an array in-place with two pointers
- Finding the second-largest distinct element

## How to Run

Compile and run one file at a time:

```bash
javac ArraySum.java
java ArraySum
```

Replace `ArraySum` with the class name of the program you want to run.
